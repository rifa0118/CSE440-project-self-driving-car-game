# Team Details Required Before Academic Submission

The software and measured technical results do not determine these identity fields, so they are deliberately not guessed. Replace the marked placeholders in the editable report and presentation with the real course/team information:

- Student name and ID for every team member
- CSE440 section
- Faculty name
- Submission date
- Presenter names and IDs
- Truthful per-member contribution breakdown
- Any faculty-provided cover-page/template requirement

These are academic metadata, not missing software functionality.
