# Submission files

This folder contains the editable Microsoft Office deliverables:

- `CSE440_Self_Driving_Car_Project_Report.docx`
- `CSE440_Self_Driving_Car_Presentation.pptx`

Before submitting, replace the clearly marked placeholders with the real team information:

1. Student names and IDs.
2. Course section.
3. Faculty member's name.
4. Submission date.
5. Truthful contribution details for every group member.
6. Presenter names and IDs on the title and conclusion slides.

All implementation descriptions and numerical results in these files are generated from the included source code, training logs, evaluation JSON, and graphs. Do not change measured results unless the corresponding experiment is rerun and the documents are updated consistently.

Regenerate both Office files after editing the generator with:

```bash
python scripts/build_submission_docs.py
```
